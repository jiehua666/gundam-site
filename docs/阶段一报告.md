## 四、启动脚本

**位置：** `D:\WY\gundam-site\scripts\`

| 脚本 | 用途 |
|------|------|
| `start-next.bat` | 启动 Next.js |
| `start-prisma.bat` | 启动 Prisma Studio |
| `start-all.bat` | 启动所有服务（菜单选择） |
| `stop-all.bat` | 停止所有服务 |

**启动命令（PowerShell）：**
```powershell
# 启动 Next.js
powershell -Command "Start-Process cmd -ArgumentList '/c npm run dev' -WorkingDirectory 'D:\WY\gundam-site' -WindowStyle Normal"

# 启动 Prisma Studio
powershell -Command "Start-Process cmd -ArgumentList '/c npx prisma studio --browser none --port 5556' -WorkingDirectory 'D:\WY\gundam-site' -WindowStyle Normal"
```

## 五、服务启动规则（重要）

**规则：所有服务必须使用有头控制台前台运行**

| 禁止 | 正确 |
|------|------|
| `npm run dev &` | 使用 PowerShell Start-Process 启动 |
| 使用 `run_in_background` | 保持控制台可见 |
| 等待用户操作 | 可自动操作时直接启动 |

**启动方式：**
1. 使用 `powershell -Command "Start-Process cmd -ArgumentList '/c ...'"` 启动
2. 不使用后台执行
3. 不使用 `&` 符号
