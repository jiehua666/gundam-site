# 阶段四报告：首页 + 机体列表 + 详情页

## 完成时间
2026-04-25

## 完成内容

### 1. 布局组件

**Navbar** (`src/components/layout/Navbar.tsx`)
- 桌面端导航栏：机体库、作品、排行、活动
- 移动端汉堡菜单
- 主题切换按钮
- 搜索快捷入口
- 用户登录状态显示
- **Logo 动画**：GUNDAM SITE 文字使用彩虹渐变流动动画（紫色→青色→红色→橙色循环，3秒一轮）
- 动画通过运行时动态注入 CSS 实现兼容

**Footer** (`src/components/layout/Footer.tsx`)
- 桌面端显示的页脚

**BottomTab** (`src/components/layout/BottomTab.tsx`)
- 移动端底部 Tab 导航（4个Tab：首页/机体/作品/我的）

**MobileNav** (`src/components/layout/MobileNav.tsx`)
- 移动端顶部横向导航（6个Tab：首页/机体/作品/活动/排行/我的）
- 与 BottomTab 互补，覆盖更多页面入口

**ClientLayout** (`src/components/ClientLayout.tsx`)
- 统一布局包装组件

> **Note:** HamburgerMenu 集成在 Navbar 中，未独立拆分为组件。

### 2. 首页模块

**Banner 横幅** (`src/components/BannerCarousel.tsx`)
- 从数据库获取 active 状态的横幅
- 首页顶部展示
- 带左右箭头切换和底部进度点
- 进度点显示当前页倒计时（从左到右增长）
- 自动轮播每5秒切换
- 手动切换后重置计时器
- 渐变淡入淡出切换效果

**HotMecha 热门机体** (`/api/mechas/hot`)
- 首页展示 5 个热门机体
- 包含封面图、名称、系列、等级
- 点击跳转详情页

**Stats 统计** (`/api/stats`)
- 机体数量、作品数量、用户数量、系列数量
- 真实数据从数据库查询

**Categories 分类** (`/api/categories`)
- 从数据库获取分类列表
- 首页展示 6 个分类入口

**Quick Links 快捷入口**
- 机体库、作品区、排行榜三个入口

> **Deferred to Phase 5:** NewCreations (新作品) - 需要先完成作品发布功能
> **Deferred to Phase 8:** FeaturedCreators (精选创作者) - 需要创作者申请和审核功能

### 3. 机体列表

**`/mechas` 页面** (`src/app/mechas/page.tsx`)
- 网格/列表视图切换
- 按系列、等级、分类筛选
- 排序功能（名称/时间）
- 分页支持

**`/api/mechas` API**
- 支持分页、筛选、排序参数
- 返回机体列表和分页信息

### 4. 机体详情

**`/mechas/[id]` 页面** (`src/app/mechas/[id]/page.tsx`)
- 封面图展示
- 基本信息（名称、系列、等级、分类）
- 基本参数（身高、重量、动力系统、装甲材质）
- 详细参数（从 MechaSpec 表获取）
- 配色方案（从 PaletteScheme 表获取）
- 相关操作按钮（喜欢、收藏、分享）

**`/api/mechas/[id]` API**
- 返回完整机体信息
- 包含 specs 和 palettes 关联数据

> **Deferred to Phase 6:** 历史版本 - 需要版本记录表和关联数据
> **Deferred to Phase 5:** 相关作品 - 需要作品系统支持关联到机体

### 5. 排行榜页面

**`/rankings` 页面** (`src/app/rankings/page.tsx`)
- 机体热度榜
- 活跃用户榜
- 真实数据展示

### 6. 活动中心

**`/activities` 页面** (`src/app/activities/page.tsx`)
- 从 `/api/missions` 获取任务数据
- 展示任务名称、描述、类型、XP 奖励
- 图标根据任务类型显示

**`/api/missions` API**
- 返回所有活跃任务

### 7. 公告页面

**`/announcements` 页面** (`src/app/announcements/page.tsx`)
- 从 `/api/announcements` 获取公告
- 支持置顶公告显示
- 发布时间显示

**`/api/announcements` API**
- 返回所有已发布公告

### 8. 全局搜索

**`/search` 页面** (`src/app/search/page.tsx`)
- 支持 URL 参数 `?q=xxx`
- 搜索机体、作品、用户
- 分别展示结果

**`/api/search` API**
- 搜索词长度 >= 2 才执行查询
- 同时搜索 mechas、creations、users

### 9. 认证安全更新

**JWT 有效期调整**
- Token 有效期：24 小时（从 7 天修改）
- Cookie 有效期：24 小时

**Token 验证机制**
- 新增 `/api/auth/me` API
- 页面加载时验证 Token 有效性
- Token 失效时自动清除登录状态

### 10. 主题系统重构

**移除 next-themes**
- 解决了 next-themes 与 Next.js 16 的兼容性问题（script 标签 hydration 错误）

**自定义 ThemeProvider** (`src/components/Providers.tsx`)
- 使用 React Context + localStorage 实现
- 支持 light/dark/system 三种模式
- 监听系统主题变化
- `useAppTheme()` hook 供组件使用

**更新的组件**
- `Navbar.tsx` - 改用 useAppTheme()
- `sonner.tsx` - 改用 useAppTheme()
