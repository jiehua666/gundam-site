# 阶段九报告：互动系统完善 + 搜索修复

## 完成时间
2026-04-27

## 完成内容

### 1. 互动 API 通知功能完善

#### likes API (`/api/likes/route.ts`)
- 用户点赞时发送通知给被点赞内容的作者
- 支持 `creation` 和 `mecha` 两种类型
- 通知类型: `like`

#### collects API (`/api/collects/route.ts`)
- 用户收藏时发送通知给被收藏内容的作者
- 支持 `creation` 类型
- 通知类型: `collect`

#### comments API (`/api/comments/route.ts`)
- 用户评论时发送通知给被评论内容的作者
- 支持 `creation` 类型
- 通知类型: `comment`
- 删除评论时减少 `commentCount`

### 2. 搜索功能修复

#### 修复 `Creation` 数据结构问题
- 原代码使用不存在的 `coverImage` 字段
- 实际数据库通过 `CreationImage` 表存储图片，`type='cover'` 为封面
- 修复 `select` 改为关联查询 `images.where(type='cover')`

#### 修复 `Image` 命名冲突
- `lucide-react` 的 `Image` 与 Next.js `Image` 组件冲突
- 重命名为 `ImageIcon`

#### 文件变更
- `src/app/api/search/route.ts` - 修复 creations 查询
- `src/app/search/page.tsx` - 修复 Image 导入和 Creation 接口

### 3. 机体详情页互动功能

#### mecha 详情页 (`/mechas/[id]/page.tsx`)
- 添加点赞/收藏状态检测 (GET `/api/likes`, `/api/collects`)
- 添加 `toggleLike` 和 `toggleCollect` 函数
- 动态更新 `likeCount` 和 `collectCount`
- 按钮状态跟随用户是否点赞/收藏

#### mecha API (`/api/mechas/[id]/route.ts`)
- 添加 `likeCount` 和 `collectCount` 字段到返回数据
