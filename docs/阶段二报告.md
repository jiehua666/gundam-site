### 5. 404问题修复（阶段二补充）
**问题**：浏览器显示404，但curl返回200

**原因**：
- `global-error.tsx` 内容错误（包含 page.tsx 内容而非错误组件）
- Sentry `withSentryConfig` 与 Next.js 16.2.4 Turbopack 冲突

**修复**：
- 修正 `global-error.tsx` 为标准错误边界组件
- 保持 `next.config.ts` 中的 `withSentryConfig` 配置
- 保留 sentry.server.config.ts, sentry.client.config.ts, sentry.edge.config.ts
- 移除 instrumentation.ts（Next.js 16 不需要）
