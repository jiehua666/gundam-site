### 1. 点赞功能

**`/api/likes` API** (`src/app/api/likes/route.ts`)

**作品详情页集成**
- 点赞按钮点击切换状态
- 实时更新点赞数
- 按钮高亮显示已点赞状态
- 刷新页面保持点赞状态

### 2. 收藏功能

**`/api/collects` API** (`src/app/api/collects/route.ts`)
- GET: 检查当前用户是否已收藏 (targetType, targetId)
- POST: 创建收藏记录，递增目标收藏数
- DELETE: 删除收藏记录，递减目标收藏数
- 支持 targetType: 'creation' | 'mecha'

**作品详情页集成**
- 收藏按钮点击切换状态

- 实时显示评论数量

### 4. 关注功能

**`/api/follows` API** (`src/app/api/follows/route.ts`)

**`FollowButton` 组件** (`src/components/user/FollowButton.tsx`)

### 5. 私信功能

**`/api/messages` API** (`src/app/api/messages/route.ts`)

## 数据库修复

**Like/Collect 表外键问题**
- 问题：多态外键（targetId 引用多个表）导致 MySQL 约束冲突
- 解决：移除多表外键约束，简化为纯关系表

```prisma
# 修改前（有问题）
model Like {
  mecha      Mecha?    @relation(...)
  creation   Creation? @relation(...)
  comment    Comment?  @relation(...)
}

# 修改后（正常）
model Like {
  userId     String
  targetType String
  targetId   String
  # 无外键约束，纯业务逻辑控制
}
```
