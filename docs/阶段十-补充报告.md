## 数据库模型

使用已有的 `Subscription` 和 `Order` 模型：

```prisma
model Subscription {
  id        String    @id @default(cuid())
  userId    String
  tier      String    @db.VarChar(20)
  status    String    @default("active")
  startAt   DateTime
  expireAt  DateTime
  autoRenew Boolean   @default(true)
  orderId   String?
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
}

model Order {
  id             String    @id @default(cuid())
  userId         String
  tier           String    @db.VarChar(20)
  amount         Decimal   @db.Decimal(10, 2)
  paymentMethod  String?   @db.VarChar(20)
  status         String    @default("pending")
  transactionId  String?   @db.VarChar(100)
  paidAt         DateTime?
  createdAt      DateTime  @default(now())
}
```

## 订阅档位设计

| 档位 | 价格 | 功能 |
|-----|------|------|
| 免费档 (free) | 0元 | 看简化版页面，基础互动 |
| 基础档 (basic) | 9元/月 | 看完整页面，每月5张图，简单收藏 |
| 标准档 (standard) | 19元/月 | 无限上传，3个3D模型，高级收藏 |

## API 详细说明

### GET /api/subscription
获取当前用户订阅状态

**响应:**
```json
{
  "subscription": {
    "id": "xxx",
    "tier": "basic",
    "status": "active",
    "startAt": "2026-04-27T00:00:00Z",
    "expireAt": "2026-05-27T00:00:00Z",
    "autoRenew": true
  },
  "tier": "basic",
  "remainingDays": 30,
  "tiers": { ... }
}
```

### POST /api/subscription
创建订阅

**请求:**
```json
{
  "tier": "basic",
  "paymentMethod": "mock"
}
```

**响应:**
```json
{
  "success": true,
  "order": { ... },
  "subscription": { ... }
}
```

### DELETE /api/subscription
取消订阅

**响应:**
```json
{
  "success": true,
  "message": "Subscription cancelled"
}
```

### GET /api/cards/reissue
获取补签卡数量

**响应:**
```json
{
  "checkinCards": 3
}
```

### POST /api/cards/reissue/use
使用补签卡补签

**请求:**
```json
{
  "date": "2026-04-25"
}
```

**响应:**
```json
{
  "success": true,
  "checkin": {
    "date": "2026-04-25",
    "xpEarned": 15,
    "consecutiveDays": 5,
    "totalDays": 20,
    "usedCard": true
  },
  "remainingCards": 2
}
```

## 支付模拟流程

1. 用户选择档位 → 点击 Subscribe/Upgrade
2. 弹出支付弹窗，选择支付方式（微信/支付宝/测试）
3. 点击确认后，调用 `POST /api/subscription`
4. 后端创建 Order 并直接标记为 paid（模拟支付成功）
5. 创建或更新 Subscription
6. 返回成功响应
