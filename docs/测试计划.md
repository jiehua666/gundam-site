## API 接口测试（可选）

### 认证相关
```bash
# 登录
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 注册（用户名需唯一）
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test123","password":"test123456","nickname":"测试用户"}'
```

### 数据获取
```bash
# 首页统计数据
curl http://localhost:3000/api/stats

# 机体列表
curl http://localhost:3000/api/mechas?limit=5

# 热门机体
curl http://localhost:3000/api/mechas/hot

# 作品列表
curl http://localhost:3000/api/creations

# 公告
curl http://localhost:3000/api/announcements

# 任务
curl http://localhost:3000/api/missions
```

### 互动功能（需登录 Cookie）
```bash
# 点赞
curl -X POST http://localhost:3000/api/likes \
  -H "Content-Type: application/json" \
  -d '{"targetType":"creation","targetId":"作品ID"}'

# 收藏
curl -X POST http://localhost:3000/api/collects \
  -H "Content-Type: application/json" \
  -d '{"targetType":"creation","targetId":"作品ID"}'
```
