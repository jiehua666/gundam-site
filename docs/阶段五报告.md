# 阶段五报告：作品系统

## 完成时间
2026-04-26

## 完成内容

### 1. 作品列表页

**`/creations` 页面** (`src/app/creations/page.tsx`)
- 网格布局展示作品卡片
- 每个卡片显示：封面图、标题、作者、点赞数、阅读数
- 点击卡片跳转到作品详情页
- "发布作品"按钮入口

**`/api/creations` API** (`src/app/api/creations/route.ts`)
- 支持分页 (page, limit)
- 排序 (sortBy: createdAt, likeCount)
- 返回作品列表和关联的作者信息、图片

### 2. 作品详情页

**`/creations/[id]` 页面** (`src/app/creations/[id]/page.tsx`)
- 封面图展示（多图时显示缩略图导航）
- 作者信息（头像、昵称、等级）
- 相关机体标签
- 统计数据（阅读、点赞、收藏）
- 作品描述内容
- 标签展示
- 发布日期
- 评论区域（集成 CommentsSection 组件）

**`/api/creations/[id]` API** (`src/app/api/creations/[id]/route.ts`)
- 返回完整作品信息
- 阅读数去重逻辑（24小时内的重复访问不计数）
- 使用 ViewHistory 表记录浏览历史

### 3. 作品发布页

**`/creations/new` 页面** (`src/app/creations/new/page.tsx`)
- 分步向导 UI（3步骤）
- 步骤1：填写作品信息（标题、描述、相关机体、标签、版权类型）
- 步骤2：添加图片（输入 URL 添加，支持预览和删除）
- 步骤3：预览确认并发布
- 发布成功后跳转到作品详情页

**`/api/creations` POST API**
- 创建作品记录
- 创建关联的 CreationImage 记录

### 4. 数据修复

**图片 URL 更新**
- 将所有假图片 URL (zhimg.com) 更新为真实图片
- 添加新的图片域名到 next.config.ts 白名单：
  - `p1.itc.cn`
  - `p3.itc.cn`
  - `staticcdn.bandaihobbysite.cn`

**统计数据重置**
- 清空所有作品的点赞数、收藏数、阅读数
- 删除测试用的 Like 和 Collect 记录

### 5. 数据库 Schema 更新

**新增 ViewHistory 表** (`prisma/schema.prisma`)
```prisma
model ViewHistory {
  id          String   @id @default(cuid())
  userId      String
  targetType  String   @db.VarChar(20)  // 'creation' | 'mecha'
  targetId    String
  viewedAt    DateTime @default(now())

  @@unique([userId, targetType, targetId])
  @@index([userId])
  @@index([targetType, targetId])
}
```

**修改 Like/Collect 表**
- 移除多表外键约束（解决 MySQL  polymorphic FK 问题）
- 简化为纯关系表
