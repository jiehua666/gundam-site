# 阶段七报告：签到系统 + 任务成就

## 完成时间
2026-04-26

## 完成内容

### 1. 签到系统

**`/api/checkins` API** (`src/app/api/checkins/route.ts`)
- GET: 获取签到状态、历史记录、统计数据
- POST: 执行签到，使用补签卡补签

**签到奖励机制**
- 第1天签到：5 XP
- 第2天签到：7 XP
- 第3天签到：9 XP
- ...
- 第13天+：29 XP（封顶）
- 公式: `5 + min(consecutiveDays - 1, 25) * 2`

**`CheckinCard` 组件** (`src/components/activities/CheckinCard.tsx`)
- 日历视图展示本月签到日期
- 连续签到天数、累计天数、补签卡数量统计
- 签到按钮（已签到/未签到状态）
- XP 奖励预览
- 月份切换

**签到与任务联动**
- 签到完成触发"每日签到"任务

### 2. 任务系统

**`/api/user-missions` API** (`src/app/api/user-missions/route.ts`)
- GET: 获取用户任务进度（按类型分组）
- POST: 更新任务进度，标记完成

**任务类型**
- `daily` - 每日任务（每日登录、每日签到）
- `once` - 一次性任务（首次评论、首次作品）
- `progress` - 进度任务（获得10赞、关注5人）
- `weekly` - 每周任务

**活动页面集成**
- 签到卡片显示在任务列表上方
- 任务卡片显示类型、描述、XP 奖励

### 3. 数据库更新

**新增 Checkin 表**
```prisma
model Checkin {
  id           String   @id @default(cuid())
  userId       String
  checkinDate  DateTime @db.Date
  xpEarned     Int      @default(0)
  cardEarned   String?
  createdAt    DateTime @default(now())

  user User @relation(fields: [userId], references: [id])

  @@unique([userId, checkinDate])
  @@index([userId])
  @@index([checkinDate])
}
```

**User 模型更新**
- 添加 `checkins Checkin[]` 关系
