## 部署指南

### PM2 部署
```bash
# 安装依赖
npm install

# 构建
npm run build

# 启动 PM2
pm2 start ecosystem.config.js

# 查看日志
pm2 logs gundam-site

# 重启
pm2 restart gundam-site
```

### Nginx 配置
```bash
# 复制配置
sudo cp nginx.conf /etc/nginx/sites-available/gundam-site
sudo ln -s /etc/nginx/sites-available/gundam-site /etc/nginx/sites-enabled/

# 测试并重载
sudo nginx -t
sudo systemctl reload nginx
```

### 环境变量
```bash
cp .env.example .env
# 编辑 .env 填写实际配置
```
